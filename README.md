# APPSC Group 1 Hub — 2026 syllabus build

This build maps the uploaded APPSC Group-I 2026 syllabus across History, Polity, Economy, Geography, Science & Environment, Aptitude and Essay. Every roadmap topic has an exam-oriented study capsule (Prelims + Mains focus), with verified-PYQ navigation. Existing detailed pages include Satavahanas, Vijayanagara, Ikshvakus and Indian Agriculture.

PYQ rule: only questions verified against an APPSC paper should be labelled PYQ; generated questions must be labelled practice/probable.
